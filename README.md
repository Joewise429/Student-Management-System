# Student-Management-System
1. Project Description

The Student Management System is a C++ program developed to manage student information. It demonstrates the use of arrays as a data structure to store and process student records.

2. Objectives

• To store student information.
• To display student records.
• To demonstrate how arrays are used to manage data.
• To make student information easier to organize.

3. Features

• Store student names and other details.
• Display stored student records.
• Manage multiple student records using arrays.

4. Data Structure Used

Array: Arrays are used to store multiple student records in an organized manner. They allow the program to access elements using indexes.

5. Programming Language

C++

6. How to Run the Program

1. Download or clone this repository.
2. Open the C++ source file in a C++ editor or IDE.
3. Compile the program using a C++ compiler.
4. Run the compiled program.
